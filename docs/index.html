Deine To‑Dos, direkt auf dem Schreibtisch.

Eine Haftnotiz für den Mac. Sie liegt hinter deinen Fenstern wie ein Widget, und du schreibst trotzdem direkt hinein.

To Do laden

Kostenlos · macOS 14 oder neuer · Version

Schreib einfach rein.

Die Notiz linksunten funktioniert wie in der App. In „Neues To-Do“ tippen, Enter. Ein Klick auf den Kreis hakt ab, ein Doppelklick auf die Überschrift benennt sie um.

Einstellungen · Design

Vierzehn Designs. Oder dein eigenes.

Hintergrund, Karte, Deko, Schrift und Farben stellst du einzeln ein, auf Wunsch mit eigenem Bild.

    Was sie sonst noch kann.

    ⌘ N
    Neue Notiz. Jede hat eigene To-Dos, ein eigenes Design und eine eigene Überschrift.
    Rechtsklick
    Abhaken, ein To-Do darunter einfügen, Erledigte entfernen.
    Ebene
    Auf dem Schreibtisch, wie ein normales Fenster oder immer im Vordergrund.
    Sprache
    Deutsch oder Englisch, umstellbar in den Einstellungen.
    Updates
    Gibt es eine neue Version, bietet die Notiz sie selbst zum Installieren an.
    Feedback
    Fehler melden oder Ideen vorschlagen, direkt über das Symbol in der Menüleiste.

    To Do laden

    ToDo.zip · · Version · macOS 14 oder neuer

    1. ZIP öffnen und To Do.app in den Ordner Programme ziehen.
    2. Die App ist nicht notarisiert. Beim ersten Start unter Systemeinstellungen → Datenschutz & Sicherheit auf Dennoch öffnen klicken.
    3. Fertig. Die Notiz liegt auf dem Schreibtisch, Updates kommen von selbst.
